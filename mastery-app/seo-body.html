Claude Mastery Workspace

A hands-on workspace for learning Claude, Anthropic's AI assistant, by doing rather than reading.

Learners progress through five levels: Master the Basics, Build with Claude, Connect Your Work, Turn Skills into Services, and Build and Scale. Each of the 42 skills starts with a real use case and a practice prompt, then an independent challenge, then a check of the real Claude answer against six questions. Each level ends with a portfolio project, and the course ends with a capstone challenge.

Features: email or Google sign-in, progress saved to each learner's account, a skills tracker, an evidence log with export, a reference guide to Claude's latest models and features, and optional live Claude runs using the learner's own API key.

Built with React, Tailwind CSS and shadcn/ui on a Node.js server with a Postgres database.
